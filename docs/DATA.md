# Data

Videos are **not** stored in Git. Put local copies in `data/videos/`.

## Sources
- **Camera footage from your teacher**: ask first, it matches the real use case.
- **UA-DETRAC**: annotated road surveillance videos (search "UA-DETRAC dataset").
- **BIT-Vehicle**: images classified by vehicle type.
- **COCO**: car and truck classes (YOLO is already pretrained on it).
- Any fixed-camera road video clip (>= 5 min) is fine for the first experiments.

## The history problem
The reference profile needs 4 to 8 weeks of data. We will generate a **synthetic history**
(realistic daily pattern with rush hours + noise) to build and test the profile and the detector,
and use real video clips to validate the vision part. State this clearly in the report.
